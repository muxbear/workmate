# 桌面版右侧“浏览器”视图实现方案

## 一、概述

在现有 `ChatSidePanel` 的“浏览器”视图中实现生产可用的单标签内嵌浏览器，使用 Electron 39 官方推荐的 `WebContentsView` 作为内核。浏览器既支持工作空间文件预览，也支持输入 `http/https` 地址。工作空间文件通过主进程控制的本地回环静态服务器加载，不直接使用 `file://`。

核心交互：

- 右栏展开后点击“切换视图”进入浏览器。
- 工作空间中点击 HTML/HTM、SVG、PDF、常见图片时自动切换到浏览器视图并加载。
- 工具栏提供后退、前进、刷新、地址输入和“在外部浏览器打开”。

## 二、总体架构

沿用现有三层结构：

```text
Vue 3 renderer
  ChatSidePanel.vue / BrowserPanel.vue
  - 地址栏、前进/后退/刷新、加载态
  - 浏览器容器 div
  - ResizeObserver 同步容器位置
        ↓ window.api
preload
  - browserNavigate
  - browserOpenWorkspaceFile
  - browserBack / Forward / Reload / Stop
  - browserSetBounds
  - browserSetVisible
  - browserOpenExternal
  - onBrowserState / onBrowserLoadError
        ↓ IPC
main process
  BrowserViewManager
  WorkspacePreviewServer
  browser IPC handlers
```

## 三、主进程实现

### 3.1 浏览器内核

- 新增浏览器内核管理器，每个 `BrowserWindow` 持有一个 `WebContentsView`。
- `WebContentsView` 使用独立分区 `persist:ke-work-browser`。
- 强制安全配置：
  - `sandbox: true`
  - `contextIsolation: true`
  - `nodeIntegration: false`
  - `webviewTag: false`
  - 不注入 App preload
- 提供导航控制：
  - 加载 URL
  - 后退、前进、刷新、停止
  - 显示/隐藏
  - 设置宿主边界
- 主进程统一校验外部 URL，只允许 `http:` 和 `https:`。
- 禁止 `javascript:`、`data:`、`file:` 及自定义危险协议。

### 3.2 工作空间预览静态服务器

新增工作空间预览静态服务器：

- 使用 Node 内置 `http` 模块，绑定 `127.0.0.1` 和随机端口。
- 每个工作空间创建一次性随机 token，token 映射到已校验的工作空间根目录。
- 路由严格限制在工作空间根目录内。
- 对真实路径做 containment 校验，防止 `..` 与符号链接逃逸。
- 支持主文件类型：
  - `.html`
  - `.htm`
  - `.svg`
  - `.pdf`
  - `.png`
  - `.jpg`
  - `.jpeg`
  - `.gif`
  - `.webp`
  - `.bmp`
- 同时为子资源提供 MIME：
  - `.css`
  - `.js`
  - `.mjs`
  - `.json`
  - `.ico`
  - `.woff2` 等
- 对 PDF 等文件支持 HTTP `Range` 请求。
- 不提供目录列表。
- 本地文件响应使用 `Cache-Control: no-store`。

### 3.3 代理同步

修改系统代理逻辑，`network.proxyMode/proxyUrl` 变更时同时应用到：

- `defaultSession`
- `persist:ke-work-browser` 分区

### 3.4 生命周期

- 窗口关闭时销毁 `WebContentsView`，并停止无引用的预览服务器。
- 登出时隐藏浏览器视图，撤销所有工作空间 token。
- `render-process-gone` 时销毁并重建视图，向渲染层推送错误状态。
- 打开设置、确认框等全局弹窗时，由渲染层调用 `browserSetVisible(false)` 隐藏内核，避免覆盖 DOM 弹层。

## 四、Preload / IPC 接口

新增浏览器相关 IPC：

| Channel | 说明 |
| --- | --- |
| `browser:navigate` | 加载外部 `http/https` URL |
| `browser:open-workspace-file` | 按 `workspaceId + relPath` 创建本地预览 token，返回友好显示地址 |
| `browser:back` | 后退 |
| `browser:forward` | 前进 |
| `browser:reload` | 刷新 |
| `browser:stop` | 停止 |
| `browser:set-bounds` | 设置内核在窗口内容区中的边界 |
| `browser:set-visible` | 切换内核显隐 |
| `browser:open-external` | 用系统方式打开当前页面 |
| `browser:state-changed` | 推送浏览器状态 |
| `browser:load-error` | 推送加载失败信息 |

`window.api` 增加：

```ts
browserNavigate(url: string): Promise<IpcResult<null>>
browserOpenWorkspaceFile(
  workspaceId: string,
  relPath: string
): Promise<IpcResult<{ displayUrl: string }>>
browserBack(): Promise<IpcResult<null>>
browserForward(): Promise<IpcResult<null>>
browserReload(): Promise<IpcResult<null>>
browserStop(): Promise<IpcResult<null>>
browserSetBounds(
  rect: { x: number; y: number; width: number; height: number }
): Promise<IpcResult<null>>
browserSetVisible(visible: boolean): Promise<IpcResult<null>>
browserOpenExternal(): Promise<IpcResult<null>>
onBrowserState(cb: (state: BrowserState) => void): () => void
onBrowserLoadError(cb: (error: string) => void): () => void
```

类型定义：

```ts
export interface BrowserState {
  displayUrl: string
  canGoBack: boolean
  canGoForward: boolean
  isLoading: boolean
}
```

IPC 返回继续沿用现有 `IpcResult<T>` 包装。除 `set-bounds`、`set-visible` 外，所有浏览器业务 IPC 都经过 `session.requireUserId()` 校验。

## 五、Vue 侧实现

### 5.1 BrowserPanel

新增 `BrowserPanel.vue`，作为浏览器视图的工具栏和宿主容器。

工具栏：

- 后退
- 前进
- 刷新
- 地址输入框
- 在外部浏览器打开

地址栏显示规则：

- 外部页面显示真实 `http/https` 地址。
- 工作空间文件显示友好地址：`workspace://<workspaceId>/<relPath>`。
- 输入普通关键词时按搜索处理，默认搜索 `https://www.bing.com/search?q=...`。
- 输入 `workspace://...` 时解析工作空间 ID 和相对路径并调用本地文件打开。

### 5.2 ChatSidePanel 改造

- 替换“浏览器视图开发中”占位。
- 监听：
  - 右侧栏展开/收起
  - 视图切换
  - 全屏
  - 窗口缩放
  - 右侧栏拖宽
- 使用 `ResizeObserver` + `requestAnimationFrame` 同步浏览器宿主 `DOMRect` 到主进程。
- 浏览器视图不可见时调用 `browserSetVisible(false)`。

### 5.3 工作空间文件触发

文件触发规则：

- `openFile` 中遇到浏览器兼容扩展名时，不再进入普通文件标签预览，而是切换到浏览器视图并调用 `browserOpenWorkspaceFile`。
- 兼容扩展名：
  - `.html`
  - `.htm`
  - `.svg`
  - `.pdf`
  - `.png`
  - `.jpg`
  - `.jpeg`
  - `.gif`
  - `.webp`
  - `.bmp`
- 浏览器打开失败时保留错误提示。
- PDF 打开失败可回退到现有 `PdfPreview`。

### 5.4 在外部浏览器打开

- 当前为 `http/https` 地址时调用 `shell.openExternal`。
- 当前为 `workspace://` 时解析并打开对应磁盘文件，交由系统默认关联程序处理。

## 六、安全策略

### 6.1 进程隔离

- 浏览器内核单独 `partition`，不和 App 默认会话共享 Cookie。

### 6.2 不注入 preload

- 第三方网页不能拿到 `window.api`，否则整个桌面端权限都会被绕过。

### 6.3 权限与协议

- 禁止 `nodeIntegration`，开启 `sandbox`、`contextIsolation`。
- 默认只允许 `http:`、`https:`。
- `javascript:`、`data:`、`file:` 默认禁止。
- `window.open` 一律交给系统浏览器处理。
- `will-attach-webview` 被阻止。
- 权限请求默认拒绝，仅允许必要的剪贴板写入。

### 6.4 下载与恢复

- 下载先弹保存路径确认，或至少落到系统下载目录并校验文件名。
- 监听 `render-process-gone`，销毁并重建 `WebContentsView`。

### 6.5 登出清理

- 登出时至少隐藏浏览器视图。
- 敏感场景下 `browserSession.clearStorageData()` 清 Cookie、缓存、LocalStorage。

## 七、关键边界与风险

### 7.1 WebContentsView 覆盖 DOM

`WebContentsView` 不是 DOM 元素，是独立图层。浏览器视图可见时，如果打开设置、确认框等全局弹窗，它可能盖住这些弹窗。

处理：

- 所有全局弹窗打开前调用 `browserSetVisible(false)`。
- 关闭后恢复。

### 7.2 坐标同步

必须覆盖所有尺寸变化：

- 右栏拖宽
- 侧栏收起
- 窗口缩放
- 全屏切换
- 系统 DPI 变化

漏一个就会出现浏览器偏位或挡住聊天区。

## 八、测试计划

### 8.1 单元 / 集成测试

- URL 白名单：
  - `http/https` 放行
  - `javascript:`、`data:`、`file:` 拒绝
- 工作空间预览服务器：
  - 正常文件与子资源返回正确 MIME
  - `..` 路径穿越、绝对路径、符号链接逃逸均被拒绝
  - PDF Range 请求正常
  - token 撤销后请求返回 404/403
- `BrowserViewManager`：
  - 导航状态
  - 后退、前进
  - 渲染进程崩溃恢复逻辑

### 8.2 安全回归

- 浏览器 IPC 未登录调用时被会话校验拦截。
- 第三方网页无法访问 `window.api`。
- `will-attach-webview` 被阻止。
- 权限请求默认拒绝，仅允许必要的剪贴板写入。
- 工作空间文件只能通过主进程解析后的 token 访问，不能由渲染层伪造任意本地路径。

### 8.3 E2E

- 登录并选择历史对话，展开右栏，切换到浏览器视图。
- 在工作空间放置 `index.html` 及相对 CSS/JS/图片资源，点击文件后自动切到浏览器视图并正确渲染。
- 点击 HTML 内相对链接、浏览器后退、前进、刷新、地址栏输入外部 URL、打开外部浏览器。
- 点击 PDF 和图片文件，确认在浏览器视图中由 Chromium 原生渲染。
- 右栏拖宽、窗口缩放、全屏切换时，浏览器边界不偏移、不遮住聊天区。
- 打开设置/确认弹窗时浏览器内核隐藏，关闭后恢复。
- 登出后浏览器视图隐藏，工作空间 token 失效。

## 九、实施顺序

### 第一阶段：单标签 MVP

- `BrowserViewManager` 单实例
- 地址栏、后退、前进、刷新、停止
- 坐标同步
- 切换视图时显隐
- URL 白名单
- 新窗口转系统浏览器
- 工作空间文件预览

### 第二阶段：生产加固

- 权限申请拦截
- 下载管理
- 代理同步
- Cookie/缓存清理
- 加载失败、渲染进程崩溃恢复
- 设置项：默认主页、搜索引擎、下载目录

### 第三阶段：更完整的浏览器体验

- 多标签页
- 书签、历史记录
- 页面内查找
- 缩放
- 快捷键
- 独立浏览器配置页

## 十、假设与默认值

- v1 只做单标签浏览器，不做多标签、书签、持久历史记录或下载管理器。
- 浏览器分区允许持久 Cookie，但 UI 不提供历史记录与书签管理。
- 默认搜索为 Bing，后续可在设置中配置。
- 工作空间本地预览使用 Node 内置 HTTP 服务，不新增静态服务器依赖。
- PDF 点击行为由现有 `PdfPreview` 改为优先进入浏览器视图，但保留失败回退路径。
- 本方案只规划实现，不改变现有登录、工作空间解析和会话校验模型。
